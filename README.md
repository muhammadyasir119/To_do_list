# 📋 To-Do List CLI

A simple command-line To-Do List application built in Python. Users can add and view tasks using a menu-driven interface.

---

## 🚀 Features

- Add tasks
- View tasks with numbering
- Delete tasks
- Menu-driven interface
- Runs in a loop until exit
---

## 🛠️ Technologies Used

- Python 3

---

## 📂 Project File

- `todo_list.py`
- `todo_list_advanced.py`
---

## ▶️ How to Run

1. Run the program:
```bash
python todo_list.py
```
